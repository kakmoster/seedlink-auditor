Configuration

Folders to Compare

Set your original downloads/media folder as Primary (Folder A) and cross-seed folder(s) as Secondary (Folder B+). In Docker, mount a single shared parent directory (e.g. /path/to/data:/data) so hardlinks share the same filesystem.

qBittorrent Instances

Connect one or more qBittorrent WebUI endpoints. Use Path Mappings if qBittorrent reports container paths (e.g. /downloads) that differ from SeedLink's local path (e.g. /data/torrents).

Radarr & Sonarr Instances

Connect Radarr/Sonarr v3 APIs to verify file imports, detect wanted releases stuck in downloads, and trigger imports or library rescans. Use Path Mappings if Radarr/Sonarr uses different container paths than SeedLink Auditor.
